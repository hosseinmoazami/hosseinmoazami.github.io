# hossein.cloud

Personal portfolio for Hossein Moazami, a Senior DevOps & Platform Engineer.

The site uses dependency-free HTML and CSS and is served directly by GitHub Pages. It includes selected engineering work, experience, technical writing, and an HTML/PDF résumé.

## Local preview

```bash
python3 -m http.server 8000
```

Open `http://localhost:8000`, then validate changes with:

```bash
python3 scripts/validate_site.py
```
